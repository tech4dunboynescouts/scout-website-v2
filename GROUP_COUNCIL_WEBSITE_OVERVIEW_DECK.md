# Group Council Presentation Deck
## New Scout Group Website Overview

Use this document as a slide-by-slide script when building your PowerPoint, Google Slides, or Keynote deck.

---

## Brand Theme Reference (Use Across All Slides)

### Core Website Palette
- Navy Dark: `#0D2044`
- Navy Mid: `#1A3A6B`
- Navy Light: `#2A5298`
- Orange Main: `#E8640A`
- Orange Hover/Accent: `#FF7D1F`
- Background: `#F4F6FA`
- Text Dark: `#0D1B35`
- Text Muted: `#5A6A8A`

### Section Colours (Great for tagged examples)
- Group Council: `#5A6A8A`
- Beavers: `#E8640A`
- Cubs: `#2A5298`
- Scouts: `#1A3A6B`
- Ventures: `#0D2044`
- Rovers: `#6B4E71`

### Typography
- Headings: Roboto Bold (700-900)
- Body: Roboto Regular/Medium (400-500)

### Slide Design Rules
- Use light background (`#F4F6FA`) for content-heavy slides.
- Use navy dark (`#0D2044`) background for section break slides.
- Use orange (`#E8640A`) only for key highlights, numbers, or CTA text.
- Keep 1 visual focal point per slide (one screenshot, one chart, or one quote).
